# vite-ember-ssr-experiment

An Ember application using vite-ember-ssr with data from https://publicatie.gelinkt-notuleren.vlaanderen.be/

This application is a hybrid SSG-SSR setup.

The following routes are SSG rendered:
- Index
- About

The following routes are SSR rendered:
- Publicaties



See https://github.com/evoactivity/vite-ember-ssr/tree/main/test-apps for more examples

See https://github.com/lblod/frontend-gelinkt-notuleren-publicatie for the current fastboot setup of https://publicatie.gelinkt-notuleren.vlaanderen.be/
